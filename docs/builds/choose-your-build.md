# Choose one architecture before downloading mods

<p className="guide-lead">Project Sentinel now has a completed reference build. Sentinel Build v1.0 is the recommended maximum-realism target; the free modern route and legacy alternative remain available for users with different access or existing installations.</p>

:::success Recommended reference build
**Sentinel Build v1.0** was completed and tested on July 30, 2026. It uses Policing Redefined, Damage Tracker Framework, NexusMDT FULL, Nexus Dispatch, NPCAI, ALPR Lite, EUP, ELS, VisualV, and Better Radiance.
:::

:::danger The most important compatibility rule
The modern routes use **Policing Redefined**. Do not leave **Stop The Ped**, **Ultimate Backup**, **CompuLite**, or **GrammarPolice** active beside the verified Sentinel architecture.
:::

## Build choices

| Question | Sentinel Build v1.0 | Free Modern Build | Legacy Alternative |
|---|---|---|---|
| Best for | Reproducing the finished maximum-realism build | Building the modern foundation without premium access | Preserving an existing STP/UB/CompuLite installation |
| Police framework | Policing Redefined | Policing Redefined | Stop The Ped + Ultimate Backup |
| MDT | NexusMDT FULL | NexusMDT Lite or compatible free option | CompuLite |
| Dispatch | Nexus Dispatch | Supported free dispatch option | GrammarPolice or menu dispatch |
| Pedestrian voice | NPCAI open-ended AI conversation | Phrase-based or free voice option | STP-compatible interaction system |
| ALPR | ALPR Lite | Optional | Optional |
| Graphics baseline | VisualV + Better Radiance | Better Radiance or base graphics | Separate choice |
| Sentinel status | **Verified final build** | Supported alternative | Archived architecture |

## Rules shared by every path

1. Confirm GTA V **Legacy**, not Enhanced.
2. Version-match GTA, LSPDFR, RPH, ScriptHookV, GameConfig, and plugin releases.
3. Keep one owner for each job: one police framework, one MDT, one dispatch workflow, and separate voice keys.
4. Install one layer at a time and pass its test before continuing.
5. Make a named backup after every stable milestone.
6. Stop adding mods when the selected build passes its acceptance test.
