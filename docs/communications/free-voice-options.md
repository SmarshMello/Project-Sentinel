# Free voice alternatives

The free build separates dispatch voice from pedestrian voice.

## AIDispatch 1.0 — dispatch voice

AIDispatch accepts natural language and triggers Policing Redefined actions. It requires a Gemini API key, microphone, ScriptHookV as documented by the author, and the supported PR version.

[Open AIDispatch on LCPDFR](https://www.lcpdfr.com/downloads/gta5mods/scripts/)

Install the complete release. A major update can change audio, street-name, config, and support files; replacing only the DLL can leave a partially upgraded system.

## NPCI 2.1 — pedestrian voice

NPCI 2.1 is free and uses configured phrases. Select the PR package. It requires Microsoft Speech Platform even when the Windows engine is selected.

[Open NPCI 2.1](https://www.lcpdfr.com/downloads/gta5mods/scripts/50691-npci/)

## GrammarPolice — legacy dispatch alternative

GrammarPolice remains useful for a non-Nexus, phrase-based dispatch setup. Do not install it automatically beside Nexus Dispatch. If both are present, assign separate keys and prove they do not compete for scanner audio or status control.

## Shared voice checklist

- Correct Windows recording device
- Input level visibly moving
- Push-to-talk key not duplicated
- Microphone permission allowed
- Speech language matches the recognition model
- No Discord/overlay exclusive capture issue
- API key hidden in support logs
- One voice system tested at a time
