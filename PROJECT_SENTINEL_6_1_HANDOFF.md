# Project Sentinel 6.1 — Actual Build Guide Rewrite

This release replaces the outdated public working-build path with the real modern Sentinel architecture. It adds separate free and paid first-time guides, migration instructions, deep installation and troubleshooting pages for Policing Redefined, Damage Tracker Framework, NexusMDT/Nexus Dispatch, NPCAI, NPCI/AIDispatch, and AxonSignal. The old Stop The Ped/Ultimate Backup/CompuLite path remains available but is clearly labeled as a separate legacy branch.
